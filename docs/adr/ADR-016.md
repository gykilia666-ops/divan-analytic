# ADR-016. Переходы рынка

- **Дата:** 2026-11-02 (этап 2)
- **Статус:** принято

(триггер, 55000): OPEN → SUSPENDED|CLOSED|VOID; SUSPENDED → OPEN|CLOSED|RESOLVED|VOID; CLOSED → SUSPENDED|RESOLVED|VOID; RESOLVED и VOID терминальны. Переход SUSPENDED → OPEN допущен для снятия ошибочной приостановки; пересмотреть на этапах 5 и 7.
