# ADR-034. place_bet в одной транзакции

- **Дата:** 2026-11-04 (этап 6)
- **Статус:** принято

SECURITY DEFINER, `search_path = ''`, EXECUTE только у `authenticated`. Порядок: пользователь из `auth.uid()` → проверка полей → аккаунт (не отключен) → повтор по ключу → лимит частоты → рынок FOR SHARE → матч FOR SHARE → условия приема по часам БД (рынок OPEN, матч SCHEDULED, лига включена, до старта > 5 мин, `last_seen_at` не старше 60 мин) → `quote_version` → кошелек FOR UPDATE → повторная проверка ключа и «уже есть прогноз» → баланс → bet + STAKE_DEBIT (`operation_key = stake:<bet_id>`) + обновление кошелька. Коэффициент и выплата берутся из БД; клиентские userId/odds/payout/balance схема API отклоняет.
