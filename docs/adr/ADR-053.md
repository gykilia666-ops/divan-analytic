# ADR-053. Причина ожидания расчета вычисляется в БД

- **Дата:** 2026-11-05 (этап 9)
- **Статус:** принято

`settlement_wait_reason` повторяет ветвления `settle_market` (конфликт, рынок открыт, матч не завершен, прерван < 48 ч, неоднозначный итог, нет счета, ждет подтверждения, готов) — pgTAP сверяет причины с фактическим результатом `settle_market`. Очередь включает и матчи с конфликтом, у которых рынок уже рассчитан. Пояснение и ожидаемое время — чистая функция `explainWait`.
