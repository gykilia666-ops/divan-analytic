# ADR-071. Почтовый адрес оператора убран

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** принято

По просьбе владельца адрес для корреспонденции удален отовсюду: переменная `LEGAL_OPERATOR_ADDRESS`, поле в `resolveOperator`/`OperatorInfo`, строка в блоке оператора, тексты политики, согласия и страницы входа, `.env.example`, документация, тесты. Оператор определяется ФИО и электронной почтой; вход закрыт, пока не заданы оба значения. Остаток `LEGAL_OPERATOR_ADDRESS` в окружении безвреден (схема неизвестные ключи отбрасывает). Это меняет [ADR-066](ADR-066.md) (там было три значения). Риск: по имеющимся сведениям, согласие по ст. 9 152-ФЗ должно содержать адрес оператора; по тексту закона не проверено — вынесено владельцу в docs/legal-checklist.md, п. 3.7. Запросы субъектов принимаются только по электронной почте.
