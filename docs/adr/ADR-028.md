# ADR-028. Внутренний endpoint

- **Дата:** 2026-11-04 (этап 4)
- **Статус:** принято

`POST /api/internal/jobs/sync` только в режиме connected, `Authorization: Bearer CRON_SECRET` со сравнением постоянного времени; привилегированный клиент `createAdminClient()` используется только здесь. Lease, `job_runs` и расписание — этап 7; до тех пор параллельные вызовы безопасны за счет общего лимитера и идемпотентного upsert.
