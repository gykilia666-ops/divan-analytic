# ADR-046. Один конвейер на запуск, журнал `job_runs`

- **Дата:** 2026-11-04 (этап 7)
- **Статус:** принято

`POST /api/internal/jobs/sync`: синхронизация → рынки → подтверждение → расчет → очистка; каждый шаг изолирован, итог OK/PARTIAL/SKIPPED/FAILED записывается в `job_runs`. Очистка: корзины лимитов старше суток, `job_runs` старше 30 дней.
