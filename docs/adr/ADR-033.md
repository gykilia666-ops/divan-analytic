# ADR-033. Часовой пояс

- **Дата:** 2026-11-04 (этап 5)
- **Статус:** принято

Фильтр даты — сутки в выбранной зоне, переведенные в интервал UTC (учитываются сутки 23/25 часов при переходе на летнее время). Зона выбирается в форме (по умолчанию подставляется зона браузера); без явной зоны время показывается в зоне браузера, а фильтр даты считается в UTC — это написано на странице.
