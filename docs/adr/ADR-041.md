# ADR-041. Каталог по умолчанию — «Можно сделать прогноз»

- **Дата:** 2026-11-04 (этап 6)
- **Статус:** заменено [ADR-078](ADR-078.md)

По просьбе владельца `/matches` без параметров показывает только матчи с открытым рынком, статусом SCHEDULED и запасом > 5 минут (по часам БД); «Все предстоящие», «Завершённые» и «Все» — в фильтре. Матчи с устаревшими данными в этой области остаются видимыми с предупреждением (состояние временное, place_bet все равно откажет). Изменение `list_matches` — новой миграцией 20261107000001 (примененные миграции не правятся).
