# ADR-038. Лимит частоты

- **Дата:** 2026-11-04 (этап 6)
- **Статус:** принято

`rate_limit_buckets` (ключ `place_bet:<user_id>`, окно 60 с, 10 попыток), функция `rate_limit_hit` недоступна клиентам и вызывается внутри `place_bet`, поэтому действует и при прямом вызове RPC. IP не используется. Очистка старых строк — этап 7.
