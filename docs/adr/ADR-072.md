# ADR-072. Псевдоним придумывает сам пользователь после входа

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** изменено [ADR-073](ADR-073.md), [ADR-074](ADR-074.md), [ADR-075](ADR-075.md)

По просьбе владельца: «нельзя придумывать за пользователя его псевдоним». Порядок: вход через GitHub → `/auth/callback` (инициализация, согласия) → если имени нет, перенаправление на `/my/pseudonym?next=…` → пользователь вводит имя → `POST /api/v1/me/pseudonym` → RPC `set_pseudonym(p_name)`. БД: `profiles.display_name` стало NULL-able (NULL = «не выбран»); `ensure_user_initialized` создает профиль без имени; `generate_pseudonym` удалена; прямой UPDATE `display_name` у `authenticated` отозван, имя меняется только через `set_pseudonym`. Проверки в функции (БД — последняя инстанция, TS-зеркало `src/lib/pseudonym.ts` нужно для быстрого отклика): 3–24 символа, буквы/цифры/пробел/`.`/`_`/`-`, начало с буквы или цифры, пробелы нормализуются; зарезервированные слова (в т.ч. «Удалённый игрок», admin); совпадение (без учета регистра) с логином, именем или частью почты до `@` из данных GitHub отклоняется, иначе по рейтингу находят аккаунт; занятость — уникальный индекс из [ADR-070](ADR-070.md) (`NAME_TAKEN`); не больше 10 попыток в минуту (`rate_limit_hit`). Смена имени первоначально была разрешена той же функцией; отменена [ADR-073](ADR-073.md) (имя выбирается один раз). Рейтинг (`leaderboard_ranked`) пропускает только игроков с именем. Пока имени нет, личные страницы (`/my/bets`, `/my/stats`, `/my/wallet`) отправляют на выбор имени (`requirePseudonym`), `/my/account` доступна (чтобы можно было удалить аккаунт, подтверждение — слово «удалить»); первоначально прогнозы без имени принимались (в рейтинге игрока нет); отменено [ADR-074](ADR-074.md) — без псевдонима прогноз не принимается. Миграция 20261115000001 сбрасывает существующие имена (автоматические и скопированные из GitHub) в NULL: до выпуска настоящих пользователей нет, после выпуска такой сброс требовал бы уведомления. Документы: соглашение, политика, оба согласия говорят «вы придумываете сами» и предупреждают, что настоящее имя будет опубликовано при согласии. Альтернативы: подсказывать сгенерированные варианты (отклонено: «придумывает пользователь»), блокировать ставки без имени (отклонено в ADR-072, принято в [ADR-074](ADR-074.md)). Последствие: рейтинг создает «Вас нет в рейтинге: нет имени» у тех, кто пропустил шаг; модерация имен — только ручной сброс `display_name = null` в БД (экрана админа нет).
