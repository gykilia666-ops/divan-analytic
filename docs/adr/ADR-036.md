# ADR-036. Идемпотентность

- **Дата:** 2026-11-04 (этап 6)
- **Статус:** принято

`request_hash = md5(market|outcome|stake|quote_version)`. Повтор ключа с тем же отпечатком возвращает исходный прогноз (`replay: true`, HTTP 200 вместо 201), даже если рынок уже закрыт, и не расходует лимит. Другой отпечаток — `IDEMPOTENCY_CONFLICT`. Конкурентные запросы одного пользователя сериализуются на строке кошелька (и счетчика частоты), после блокировки ключ проверяется заново; уникальные ограничения `(user_id, idempotency_key)` и `(user_id, market_id)` — последняя линия защиты. Клиент держит один ключ на намерение: после сетевой ошибки повторяет его, при смене исхода/суммы или после отказа по существу создает новый.
