# ADR-017. Права по умолчанию отозваны

- **Дата:** 2026-11-02 (этап 2)
- **Статус:** принято

У `anon` и `authenticated` отозваны все права на таблицы и функции схемы `public`, а также default privileges; клиентам явно выданы только SELECT на публичные спортивные данные, SELECT на собственные приватные данные и UPDATE(display_name) профиля. Для функций PUBLIC-EXECUTE Postgres выдает всегда, поэтому каждая новая функция обязана делать `REVOKE ... FROM PUBLIC`. Запись в `wallets`, `wallet_entries`, `bets`, `markets`, `matches`, `user_roles` у клиентов отсутствует.
