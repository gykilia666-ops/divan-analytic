# ADR-050. Кеш рейтинга 60 секунд

- **Дата:** 2026-11-05 (этап 8)
- **Статус:** принято

Ответ одинаков для всех, поэтому кешируется в памяти экземпляра (TTL, одновременные промахи делят запрос, ошибки не кешируются) и в CDN (`s-maxage=60`). Место пользователя запрашивается отдельно и не кешируется. Кеш в памяти — на экземпляр функции; согласованность между экземплярами не требуется.
