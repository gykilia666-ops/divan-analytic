# ADR-058. Логи очищаются в одном месте

- **Дата:** 2026-11-05 (этап 10)
- **Статус:** принято

`logEvent` заменяет значения чувствительных полей (token, secret, password, authorization, cookie, api key, service role, email, jwt) на `[redacted]`, вычищает bearer-токены, JWT и email внутри строк, обрезает длинные строки и глубину. verify.ps1 дополнительно ищет значения секретов из `.env.local` в логах локальных серверов (значения не печатаются).
