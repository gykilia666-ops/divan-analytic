# ADR-060. Измерения — скрипт, а не разовые цифры

- **Дата:** 2026-11-05 (этап 10)
- **Статус:** принято

`scripts/perf/measure.mjs` (запуск `verify.ps1 -Measure`) создает в локальной БД профиль §14.1 под поставщиком `perf`, меряет функции БД под ролями anon/authenticated, HTTP p50/p95 к `next start`, холодный старт и мобильный LCP (Pixel 5, 360 px, CPU ×4, медленный 4G). Результат — `.verify/perf.json`, сводка с окружением — docs/measurements.md.
