# ADR-061. Удаление аккаунта — обезличивание, а не стирание журнала

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** принято

По просьбе владельца пользователь сам удаляет аккаунт (`/my/account`, подтверждение точным именем). `delete_my_account()` (SECURITY DEFINER, только свой auth.uid()) заменяет имя на «Удалённый игрок», убирает аватар, ставит `deleted_at` и `disabled_at`, снимает роли, пишет `ACCOUNT_DELETED` в аудит; повтор идемпотентен. Затем сервер мягко удаляет учетную запись Supabase Auth (`auth.admin.deleteUser(id, true)`): строка остается для внешних ключей, вход по ней невозможен, повторный вход через GitHub создает новый аккаунт. Прогнозы и журнал не удаляются (append-only, инвариант баланса и проверочные пересчеты), но больше не связаны с именем. Отключенный профиль уже исключен из рейтинга, приема прогнозов и прав администратора. Что именно Supabase стирает при мягком удалении (почта, identities), документацией не уточнено — проверить после первого удаления в production.
