# ADR-048. Статистика считается по `bets`, а не по журналу

- **Дата:** 2026-11-05 (этап 8)
- **Статус:** принято

WON/LOST — основной расчет; VOID и PENDING показываются отдельно и не входят в win rate, ROI и прибыль; INITIAL_CREDIT и ADMIN_ADJUSTMENT в прибыль не попадают по построению. БД возвращает только счетчики и суммы (`my_stats`, SECURITY INVOKER + RLS), проценты считаются одной чистой функцией `summarize` (нулевой знаменатель → «—»).
