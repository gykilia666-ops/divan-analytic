# ADR-045. Аренда задания с fencing по поколению

- **Дата:** 2026-11-04 (этап 7)
- **Статус:** принято

`job_leases(job_name, lease_owner, lease_until, generation)`; захват увеличивает поколение; `settle_ready_markets` перед каждым рынком вызывает `job_assert_lease` (FOR SHARE), и исполнитель с устаревшим поколением получает `LEASE_LOST` без записей. Аренда 120 с, пачка 50 рынков, ошибка одного рынка — аудит `SETTLEMENT_FAILED`, остальные продолжаются. `settle_market` не исполняется ни одной ролью напрямую.
