# ADR-068. Тексты документов описывают фактическое поведение, а не желаемое

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** принято

Политика прямо называет Supabase (Лондон), Vercel (Лондон/США), GitHub (США), cookie, сроки (10 рабочих дней на запросы, журнал согласий до 3 лет после удаления) и не обещает локализации в РФ. Структурные риски (вход только через GitHub и ст. 13.55 КоАП, локализация и трансграничная передача, уведомления РКН, что стирает мягкое удаление Supabase, ручная очистка журнала согласий) вынесены владельцу в docs/legal-checklist.md и в код не вносились без его решения. Тексты подготовлены по вторичным источникам и без юриста: перед публичным запуском показать юристу.
