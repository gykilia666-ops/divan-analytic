# ADR-019. Поток входа

- **Дата:** 2026-11-02 (этап 3)
- **Статус:** изменено [ADR-075](ADR-075.md) (callback больше не инициализирует пользователя)

`POST /auth/login` (не GET) запускает GitHub OAuth через Supabase (PKCE); `GET /auth/callback` обменивает код, вызывает `ensure_user_initialized()` и редиректит; `POST /auth/signout` завершает локальную сессию. Обе POST-команды проверяют `Origin` строго по `APP_ORIGIN` (`localhost` и `127.0.0.1` — разные origin). Адрес возврата хранится в httpOnly-cookie `divan_next` (path `/auth`, 10 минут), а не в URL, и проходит белый список корней маршрутов (`safeNextPath`). Причина: точное соответствие redirect URL у Supabase и невозможность подменить адрес ссылкой.
