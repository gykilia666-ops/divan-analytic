# ADR-039. История

- **Дата:** 2026-11-04 (этап 6)
- **Статус:** принято

Витрина `bet_history` (security_invoker: RLS `bets` оставляет только свои) и `list_my_bets` (курсор `(created_at, id)`, новые сверху, фильтр статуса). Страница `/my/bets`, API `GET /api/v1/me/bets`. В демо-режиме прогнозы не принимаются (POST → 503), купон не показывается.
