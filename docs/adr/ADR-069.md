# ADR-069. Псевдоним вместо логина и аватара GitHub

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** частично заменено [ADR-072](ADR-072.md) (имя выбирает пользователь)

По просьбе владельца: по рейтингу нельзя выйти на аккаунт GitHub. Раньше `ensure_user_initialized` копировал в профиль логин (`user_name`) и аватар GitHub; ссылка на аватар GitHub содержит числовой идентификатор аккаунта, логин ведет на публичный профиль. Теперь при первой инициализации сервис присваивает случайный псевдоним `Прилагательное_Существительное_NNNN` (`generate_pseudonym()`, 16×16×10 000 вариантов, до 21 символа, не выводится из данных пользователя; повторный вход его не меняет; уникальность — [ADR-070](ADR-070.md)). Аватар не сохраняется: колонка `avatar_url` остается, чтобы не менять форму публичных DTO, но всегда пуста (ограничение `profiles_no_avatar`, миграция 20261114000001). Существующие профили с именами не в формате псевдонима переименованы миграцией. Это меняет источник имени из [ADR-014](ADR-014.md). Данные GitHub (логин, имя, почта, аватар) по-прежнему хранит Supabase Auth (`auth.users`), клиентам они недоступны. Согласие на публикацию в рейтинге сохранено: оператор может сопоставить псевдоним с аккаунтом, поэтому он остается персональными данными. Последствия: имя нельзя выбрать самому (экрана нет, хотя колонка `display_name` редактируема владельцем через API); подтверждение удаления требует ввода псевдонима; тексты соглашения, политики и согласий изменены без смены `LEGAL_VERSION`, потому что до выпуска записей согласий нет — после выпуска любое изменение смысла требует новой версии. **Автогенерация имени заменена выбором самим пользователем — [ADR-072](ADR-072.md) (запрет аватара и скрытие логина GitHub остаются).**
