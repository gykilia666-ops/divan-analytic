# ADR-014. Инициализация пользователя

- **Дата:** 2026-11-02 (этап 2)
- **Статус:** заменено [ADR-075](ADR-075.md)

RPC `public.ensure_user_initialized()` (SECURITY DEFINER, `search_path = ''`, EXECUTE только у `authenticated`) вместо триггера на `auth.users`: функция идемпотентна и вызывается явно из auth-callback (этап 3). Профиль, кошелек и запись `INITIAL_CREDIT` вставляются через `ON CONFLICT DO NOTHING` (без целевого ограничения, чтобы перехватывать и `operation_key`, и частичный уникальный индекс); баланс растет только если запись журнала реально вставлена этим вызовом. Возвращает `(wallet_balance, credited)`. Имя: из OAuth-метаданных, без управляющих символов и `<>`, 3–24 символа, иначе `Аналитик-xxxxxx`; аватар — только https. Отключенный аккаунт получает `ACCOUNT_DISABLED`. [Заменено [ADR-075](ADR-075.md): функция удалена, профиль и кошелек создает `set_pseudonym`.]
