# ADR-021. Инициализация дважды безопасна

- **Дата:** 2026-11-02 (этап 3)
- **Статус:** заменено [ADR-075](ADR-075.md)

Кроме callback, страница кошелька повторно вызывает `ensure_user_initialized()`, если кошелька нет (вход состоялся, инициализация сорвалась). Отключенный аккаунт в callback выходит из сессии и получает сообщение `disabled`. [Заменено [ADR-075](ADR-075.md): callback ничего не инициализирует, страница кошелька не повторяет инициализацию.]
