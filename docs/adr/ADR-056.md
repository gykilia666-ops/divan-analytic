# ADR-056. CSP с nonce в proxy.ts

- **Дата:** 2026-11-05 (этап 10)
- **Статус:** принято

`script-src 'self' 'nonce-…' 'strict-dynamic'` (в dev + `'unsafe-eval'`), `style-src 'self' 'unsafe-inline'` (style-атрибуты Next/React; внешних стилей нет), `form-action 'self'` + origin Supabase + github.com (браузер проверяет цепочку редиректов входа), `frame-ancestors 'none'`, `object-src 'none'`, `base-uri 'self'`. Nonce свой у каждого ответа, поэтому RootLayout вызывает `connection()` и все страницы рендерятся динамически (статической предварительной отрисовки нет — осознанная цена). e2e проверяет заголовок и отсутствие нарушений CSP на ключевых страницах.
