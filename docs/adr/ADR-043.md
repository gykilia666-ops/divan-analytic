# ADR-043. Расчет: WON/LOST по основному времени, VOID при подтвержденной отмене/переносе и SUSPENDED > 48 ч

- **Дата:** 2026-11-04 (этап 7)
- **Статус:** принято

`settle_market` в одной транзакции блокирует рынок, матч (FOR SHARE), прогнозы и кошельки в порядке `user_id`; выплаты и возвраты — записи журнала с ключами `win:<bet>` / `refund:<bet>`, поэтому повторный расчет ничего не начисляет. Рынок не в статусе CLOSED/SUSPENDED пропускается (SKIPPED).
