# ADR-029. Демонстрационные коэффициенты

- **Дата:** 2026-11-04 (этап 5)
- **Статус:** принято

`computeDemoOdds(provider, providerMatchId, modelVersion)`: SHA-256 от ключа → три равномерных числа → веса (хозяева 0.30–0.70, ничья 0.20–0.32, гости 0.20–0.60) → нормализация → ограничение вероятностей с сохранением суммы 1 → `floor(1000 / (p × 1.06))`. Ключ — ID поставщика, а не внутренний UUID, поэтому значения переживают пересоздание БД. Итог матча не используется. Значения считаются на сервере при создании рынка и фиксируются в БД (`model_version = demo-v1`, `quote_version = 1`); изменение алгоритма требует новой версии модели (в тестах закреплены эталонные значения). На 20 000 матчей диапазон фактически 1.50–6.90, маржа 6.0–7.5%. Если коэффициенты не прошли проверку — рынок не открывается.
