# ADR-049. Рейтинг — SECURITY DEFINER с безопасным DTO

- **Дата:** 2026-11-05 (этап 8)
- **Статус:** принято

Внутренняя `leaderboard_ranked()` (с user_id) не выдана ни одной роли; публичная `leaderboard(limit 1..100)` возвращает место, имя, аватар и агрегаты; `my_leaderboard_place()` — место текущего пользователя. Допуск ≥ 5 рассчитанных, отключенные профили скрыты, сортировка net_profit ↓, settled ↓, user_id. Места уникальные (row_number), не «общие».
