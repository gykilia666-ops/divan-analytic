# ADR-009. Основное время

- **Дата:** 2026-10-26 (этап 0)
- **Статус:** принято

По документации, `score.fullTime` при `duration = REGULAR` — итог основного времени; при `EXTRA_TIME`/`PENALTY_SHOOTOUT` `fullTime` уже включает дополнительное время и пенальти. Правило: рассчитывать только при `status = FINISHED`, `duration = REGULAR` и обеих сторонах `fullTime`; при другом `duration` брать `regularTime` только если оно непусто, иначе результат неоднозначный (проверка, без догадок). Последствие: для лиг дополнительное время не возникает, но правило остаётся защитой.
