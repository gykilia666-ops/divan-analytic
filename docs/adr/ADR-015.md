# ADR-015. Инварианты в БД, а не только в коде

- **Дата:** 2026-11-02 (этап 2)
- **Статус:** принято

Журнал append-only (триггер, SQLSTATE 55000). `balance = SUM(wallet_entries.amount)` проверяется отложенным constraint-триггером при COMMIT (23514), поэтому запись журнала и обновление кошелька допустимы в любом порядке внутри транзакции. Принятый прогноз неизменяем, кроме `status/actual_payout/settled_at` из PENDING (55000). `potential_payout = floor(stake * odds / 1000)` — CHECK. CHECK состояний прогноза использует явные `is not null`: CHECK пропускает NULL-результат выражения.
