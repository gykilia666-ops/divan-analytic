# ADR-020. Проверка пользователя

- **Дата:** 2026-11-02 (этап 3)
- **Статус:** принято

`proxy.ts` только обновляет сессию; авторизация выполняется в страницах и API через `getCurrentUser()` (getClaims). Защищенные страницы вызывают `requireUser()` (редирект на `/login?next=…`), API отвечает 401 `UNAUTHENTICATED` по контракту. Ошибки БД клиенту не раскрываются (503 `SERVICE_UNAVAILABLE`).
