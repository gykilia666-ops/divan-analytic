# ADR-035. Бизнес-отказы — ответом, а не исключением

- **Дата:** 2026-11-04 (этап 6)
- **Статус:** принято

`place_bet` возвращает `{ok:false, code}`: транзакция фиксируется, и счетчик частоты учитывает отклоненную попытку. Исключения — только для неожиданных ошибок; API превращает их в 503 без деталей. Коды → HTTP по §11.2; добавлен `ACCOUNT_NOT_READY` (409) для пользователя без профиля/кошелька.
