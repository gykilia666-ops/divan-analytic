# ADR-040. «Вошел» = есть профиль

- **Дата:** 2026-11-04 (этап 6)
- **Статус:** принято

Подписанный токен не гарантирует существование аккаунта: после удаления пользователя (в т. ч. `db:reset` локально) или сбоя инициализации старая cookie остается валидной. Страница `/login` перенаправляет дальше только при наличии профиля; иначе показывает вход, и новый вход заменяет устаревшую сессию. Найдено владельцем: в старом браузере вход «перебрасывал на главную».
