# ADR-054. Ручной запуск — тот же конвейер под той же арендой

- **Дата:** 2026-11-05 (этап 9)
- **Статус:** изменено [ADR-057](ADR-057.md) (лимит ручного запуска)

`admin_request_sync()` проверяет роль, ограничивает запуск одним в минуту на всех администраторов и пишет аудит с автором; затем сервер выполняет `executeSyncJob` (общий с cron). Параллельный cron получает SKIPPED/LEASE_HELD. Привилегированный клиент используется только после проверки роли.
