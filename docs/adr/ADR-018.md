# ADR-018. Поэтапное создание таблиц

- **Дата:** 2026-11-02 (этап 2)
- **Статус:** принято

Служебные таблицы (`job_runs`, `job_leases`, `sync_cursors`, `provider_rate_limits`, `audit_events`, `rate_limit_buckets`, `user_stats`) создаются на этапах 7–9 expand-only миграциями. Внешние ключи без каскадного удаления: удаление аккаунта потребует отдельной процедуры обезличивания.
