# ADR-064. Тема «День/Ночь» через cookie, шрифт логотипа через next/font

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** принято

Выбор темы — cookie `theme` (light|dark, год), RootLayout ставит `data-theme` на `<html>` при серверной отрисовке: без мигания и без inline-скрипта (CSP). Без выбора действует `prefers-color-scheme`. Переключатель — `useSyncExternalStore` (следит и за системной темой). Логотип — Russo One (кириллица) через `next/font/google`: файл скачивается при сборке и раздается с нашего домена, CSP не меняется. Сборка требует доступа к Google Fonts (локально, CI, Vercel — есть).
