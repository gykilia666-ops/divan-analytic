# ADR-042. Подтверждение итога — два одинаковых наблюдения с интервалом ≥ 10 минут

- **Дата:** 2026-11-04 (этап 7)
- **Статус:** принято

Отпечаток итога (`FINISHED:h:a`, `CANCELLED`, `POSTPONED`) сохраняется при первом наблюдении; `result_confirmed_at` ставится, когда тот же отпечаток виден снова не раньше чем через 600 с. AMBIGUOUS и иные состояния не подтверждаются и не рассчитываются автоматически.
