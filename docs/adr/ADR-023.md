# ADR-023. Маппинг статусов явный

- **Дата:** 2026-11-04 (этап 4)
- **Статус:** принято

TIMED/SCHEDULED → SCHEDULED; IN_PLAY/PAUSED/EXTRA_TIME/PENALTY_SHOOTOUT → LIVE; FINISHED и AWARDED → FINISHED; SUSPENDED, POSTPONED, CANCELLED — как есть; неизвестный статус отбрасывает элемент (учитывается как invalid). AWARDED дает результат AMBIGUOUS (технический итог не рассчитывается). Время без зоны отбрасывается.
