# ADR-059. Лимиты чтения не вводятся до облачных измерений

- **Дата:** 2026-11-05 (этап 10)
- **Статус:** принято

§13.5 требует выбирать их после измерений; локальные числа (docs/measurements.md) не отражают сеть и холодные старты Vercel. Публичные чтения защищены кешем (матчи 30 с, рейтинг 60 с, CDN `s-maxage`). Вернуться на этапе 11 по облачным метрикам.
