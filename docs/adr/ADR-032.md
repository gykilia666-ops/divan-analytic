# ADR-032. Каталог

- **Дата:** 2026-11-04 (этап 5)
- **Статус:** принято

Витрина `public.match_catalog` (security_invoker, только включенные соревнования) и функция `list_matches` (фильтры: поставщик, соревнование, интервал UTC, scope; курсор `(kickoff_at, id)`; возвращает limit + 1 строку как признак следующей страницы). Одна серверная реализация для страниц и `GET /api/v1/matches[/:id]`; в демо — тот же контракт поверх fixtures. Публичный API кешируется на 30 с (`s-maxage=30`).
