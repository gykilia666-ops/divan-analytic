# ADR-031. Обслуживание рынков в синхронизации

- **Дата:** 2026-11-04 (этап 5)
- **Статус:** принято

После загрузки матчей (и даже если поставщик недоступен) `sync_close_markets()` приостанавливает рынки перенесенных/прерванных/отмененных матчей и закрывает рынки с истекшим сроком или начавшихся/завершенных матчей; приостановленный рынок доигранного матча закрывается для расчета. Автоматического переоткрытия нет. Отмена в этапе 5 только приостанавливает рынок: VOID с возвратом ставок делает расчет (этап 7). Затем `sync_matches_needing_market` + `sync_create_markets` создают недостающие рынки (ON CONFLICT DO NOTHING, повторная проверка времени по часам БД). Все три функции — только `service_role`.
