# ADR-044. Изменение итога после расчета не переписывает историю

- **Дата:** 2026-11-04 (этап 7)
- **Статус:** принято

Если подтвержденный отпечаток меняется у рассчитанного (RESOLVED) рынка — `result_conflict_at`, одна запись `RESULT_CHANGED_AFTER_SETTLEMENT` в `audit_events`, матч исключается из автоматики до `admin_ack_result_conflict`. Исправление денег — только `admin_compensate` (новая запись журнала, уникальный ключ, баланс не уходит в минус). Изменение VOID-рынка (отмена → перенос) конфликтом не считается.
