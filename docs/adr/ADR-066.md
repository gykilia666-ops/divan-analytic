# ADR-066. Данные оператора — из переменных окружения, вход закрыт без них

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** изменено [ADR-071](ADR-071.md) (адрес оператора убран)

Политика обязана называть оператора и контакты. ФИО, почта и адрес владельца не коммитятся в публичный репозиторий: `LEGAL_OPERATOR_NAME/EMAIL/ADDRESS` (Vercel, Production); адрес позже убран, см. [ADR-071](ADR-071.md). Без любой из трёх (или с некорректной почтой) `POST /auth/login` отвечает 503, на страницах документов видна пометка. Это сознательный fail-closed: собирать ПДн, не назвав оператора, нельзя. Последствие: после выпуска вход не заработает, пока переменные не заданы.
