# ADR-055. Снятие конфликта из админки — с причиной и автором

- **Дата:** 2026-11-05 (этап 9)
- **Статус:** принято

`admin_resolve_conflict` вызывает `admin_ack_result_conflict` (прямо пользователю не выдана) и пишет `ADMIN_CONFLICT_RESOLVED` с user_id. Компенсации остаются в SQL владельца (runbook): денежные операции не выносятся в веб-интерфейс MVP.
