# ADR-063. Плашка режима — только в demo

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** принято

По решению владельца в рабочем режиме плашки «Режим connected» нет: она не несет пользователю новой информации, а задержка данных указана на страницах матчей («Последнее обновление», предупреждения об устаревших данных). Требование §19.1 «режим виден в интерфейсе/диагностике» выполняется через `/admin` (строка «Режим: …»). В demo плашка остается: там данные вымышленные. Заодно все рамки скруглены сильнее (`rounded` → `rounded-lg`).
