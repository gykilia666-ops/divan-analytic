# ADR-077. Согласие — подписью под кнопкой входа, без галочек

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** принято

По просьбе владельца: «убери галочки, добавь снизу маленькие подписи, как на настоящих спортивных сайтах». Форма входа содержит только кнопку «Войти через GitHub» и мелкую подпись со ссылками на Соглашение, Согласие на обработку ПДн и Политику; нажатие считается согласием и подтверждением 18+. Серверная проверка отметок и `CONSENT_FIELDS`/`parseConsentForm` удалены; cookie `divan_consent` (версия документов) и запись в журнал `user_consents` через `record_consents` остаются, то есть доказательство (версия, время, пользователь) сохраняется. Риск: с 01.09.2025 152-ФЗ требует, чтобы согласие на обработку ПДн было конкретным, информированным и сознательным, отдельным от иных документов; подпись «нажимая, вы соглашаетесь» оспаривается проще, чем отдельная отметка (позиция Роскомнадзора по такому способу известна только из вторичных источников). Решение принято владельцем; при споре вернуть отметки можно только кодом формы и маршрута `/auth/login`. `LEGAL_VERSION` не менялась.
