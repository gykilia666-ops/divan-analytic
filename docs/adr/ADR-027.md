# ADR-027. Ошибки поставщика

- **Дата:** 2026-11-04 (этап 4)
- **Статус:** принято

429 — пауза и стоп; 401/403 — ошибка настройки (`configError`), без повторов; таймаут, сеть и 5xx — пропуск соревнования, остальные продолжают; повторы внутри запуска не делаются (их роль выполняет следующий запуск cron, этап 7). Сбой не удаляет и не портит сохраненные матчи.
