# ADR-062. Фон с параллаксом — лицензионное фото, а не генерация

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** принято

По просьбе владельца: реалистичный удар крупным планом. Взято фото Alfonso Scarpa с Unsplash (лицензия Unsplash: бесплатно, в том числе коммерчески, без обязательной атрибуции; атрибуция все равно в футере). Кадр — бутса и мяч, лицо не видно (нет прав на изображение личности). Файл `public/images/bg-kick.webp` (2400 px, WebP q70) отдается через next/image (`/_next/image`, CSP `img-src 'self'` не меняется). Слой `fixed`, `-z-10`, `aria-hidden`, `pointer-events: none`; смещение пропорционально прогрессу прокрутки (весь путь страницы = 18 % высоты окна), rAF + passive listeners, при `prefers-reduced-motion` неподвижен; полупрозрачная подложка цвета темы сохраняет контраст текста. Цена — дополнительная картинка на первой загрузке: мобильный LCP перемерить.
