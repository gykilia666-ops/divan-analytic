# ADR-052. Роль администратора проверяется в БД при каждом запросе

- **Дата:** 2026-11-05 (этап 9)
- **Статус:** принято

`is_admin()` читает только `user_roles` (не профиль и не user metadata) и учитывает `disabled_at`. Все админ-функции — SECURITY DEFINER с `admin_assert()` внутри: прямой вызов через PostgREST обычным пользователем → 42501 FORBIDDEN, гостю EXECUTE не выдан. Страница `/admin` не администратору и в demo отвечает 404 (раздел не раскрывается); API — 401/403/404 по контракту.
