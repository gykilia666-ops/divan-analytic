# ADR-026. Upsert атомарный и идемпотентный

- **Дата:** 2026-11-04 (этап 4)
- **Статус:** принято

`sync_upsert_matches(provider, payload)`: одна транзакция; дубликаты внутри payload схлопываются (у матча — самое свежее наблюдение); `provider_updated_at` старее сохраненного не перезаписывает состояние, null не новее известного; `last_seen_at` обновляется всегда; `enabled` соревнования при импорте не трогается; ссылка на неизвестную команду/соревнование отклоняет весь payload. Функции доступны только `service_role`.
