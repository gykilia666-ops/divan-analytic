# ADR-010. Выборка матчей

- **Дата:** 2026-10-26 (этап 0)
- **Статус:** принято, уточнено 2026-11-04

`GET /v4/matches` без параметров возвращает матчи только за сегодня (UTC). Для синхронизации нужны явные фильтры дат или подресурс соревнования; точные параметры, максимальную длину диапазона и поведение для free-токена **проверить запросом с токеном на этапе 4**. Бюджет: ≤ 8 запросов/мин при лимите провайдера 10/мин.

## Уточнения

- 2026-11-04 (уточнен): синхронизация — один запрос `/competitions/{code}/matches` на соревнование с окном «2 дня назад … 7 дней вперед» (9 дней; подтверждено, что 10 дней работают). Итого 3 запроса за запуск.
