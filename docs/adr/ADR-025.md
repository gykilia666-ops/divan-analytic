# ADR-025. Общий лимитер в БД

- **Дата:** 2026-11-04 (этап 4)
- **Статус:** принято

Таблица `provider_rate_limits` и функция `provider_try_acquire` (FOR UPDATE, окно 60 с, лимит 8); `provider_report_rate_limited` сохраняет `next_allowed_at` по Retry-After или `X-RequestCounter-Reset` (не дольше часа, более короткая пауза не сокращает назначенную). Внутри функции не ждем: исчерпанный бюджет или 429 завершают обход, следующий запуск продолжит.
