# ADR-078. Каталог матчей по умолчанию показывает «Предстоящие»

- **Дата:** 2026-11-05 (этап 11)
- **Статус:** принято

По просьбе владельца пункт «Можно сделать прогноз» убран из фильтра: значения `scope` в приложении — `upcoming` (по умолчанию), `finished`, `all`; адрес без параметра `scope` = предстоящие. Функция БД `list_matches` по-прежнему умеет `p_scope = 'open'` (миграцию не меняли, на неё опираются pgTAP 05 и замер производительности), но из приложения этот режим недостижим. Состояние приема по карточке (`acceptance`) показывается как раньше.
