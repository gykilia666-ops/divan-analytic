# ADR-047. Cron — шаблон SQL, а не миграция

- **Дата:** 2026-11-04 (этап 7)
- **Статус:** принято

`supabase/cron/schedule-sync.sql` (pg_cron + pg_net, адрес и секрет в Vault) выполняется вручную в облачном проекте: миграции не должны содержать адрес развертывания и секреты, а локальная база не должна вызывать production.
