# Аналитическая документация «Диванный аналитик»

Пакет документов системного аналитика: от видения продукта до трассировки требований в код и тесты.
Описывает систему в том виде, в каком она реализована и проверена на 06.11.2026 (релиз 7c4410b,
этап 11). Требования пронумерованы; каждое прослеживается до реализации и тестов
([11-traceability.md](./11-traceability.md)).

## Соглашения

- **Идентификаторы.** `BR-nn` — бизнес-требование, `BRL-nn` — бизнес-правило, `FR-<модуль>-nn` —
  функциональное, `NFR-nn` — нефункциональное, `UC-nn` — вариант использования, `US-nn` — история,
  `R-nn` — риск, `Q-nn` — открытый вопрос. Номера не переиспользуются.
- **Приоритет** (MoSCoW): Must — без этого нет MVP; Should — важно, но есть обходной путь; Could — желательно;
  Won't — сознательно не делаем в MVP.
- **Статус требования:** «Реализовано» — есть код и автоматический тест; «Частично» — есть код, проверка
  ручная; «План» — после MVP.
- **Термины** — в глоссарии [06-data-model.md](./06-data-model.md#глоссарий).
- **Диаграммы** — Mermaid; GitHub отрисовывает их прямо в файлах.
- **Изменение требований** — новая версия документа и запись в журнале ниже; архитектурные последствия —
  новый ADR в [`docs/adr/`](../adr/README.md). SQL примененных миграций не правится (только новые миграции).
