# Измерения (этап 10)

Фактические результаты `scripts/perf/measure.mjs` (запуск: `verify.ps1 -Measure`) от 2026-11-05.
Это **локальные** числа: сеть, регион и холодные старты Vercel/Supabase Cloud они не отражают — облачные
измерения повторяются на этапе 11 (docs/requirements.md §14.2).

## Окружение

| Параметр               | Значение                                                                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Машина                 | AMD Ryzen 5 6600H (12 потоков), 15 ГБ RAM, Windows 10.0.26200                                                                          |
| Приложение             | `next start` (production build), Node v24.15.0, режим connected, поставщик fixtures                                                    |
| БД                     | локальный Supabase (Docker) на той же машине, PostgreSQL 17                                                                            |
| Профиль данных (§14.1) | 50 пользователей, 2 000 матчей, 10 000 прогнозов (5 000 рассчитаны) под поставщиком `perf`; всего в БД 2 067 матчей и 10 012 прогнозов |

## Функции БД (роли anon/authenticated, параллельность 10)

Время включает транзакцию, смену роли и сетевой круг до Docker, без HTTP.

| Функция                                         |   n | p50, мс | p95, мс | max, мс |
| ----------------------------------------------- | --: | ------: | ------: | ------: |
| `list_matches` (можно сделать прогноз, 20 шт.)  | 300 |    22.2 |    38.5 |    68.2 |
| `list_matches` (все, первая страница)           | 300 |    20.2 |    26.0 |    32.6 |
| `list_my_bets` (200 прогнозов у пользователя)   | 300 |     9.2 |    16.3 |    26.7 |
| `my_stats`                                      | 300 |     2.0 |     3.1 |     5.4 |
| `leaderboard(50)` (агрегат по 10 000 прогнозов) | 200 |    49.6 |    57.8 |    65.2 |
| `place_bet` (50 пользователей × 4)              | 200 |     9.5 |    18.4 |    35.3 |

`place_bet`: принято 200 из 200, отказов нет. Рейтинг — самая тяжелая функция, поэтому он кешируется на 60 с.

## HTTP (прогретый сервер, параллельность 10)

Каталог через HTTP обслуживает данные поставщика fixtures (12 матчей), а не профиль `perf`: поставщик задается
окружением. Рейтинг через HTTP включает профиль `perf` и отдается из 60-секундного кеша.

| Запрос                         |   n | p50, мс | p95, мс | max, мс | Цель §14.2 |
| ------------------------------ | --: | ------: | ------: | ------: | ---------- |
| `GET /api/v1/matches`          | 200 |    57.0 |    90.8 |   201.8 | p95 ≤ 800  |
| `GET /matches` (страница)      | 200 |    97.7 |   132.8 |   149.3 | p95 ≤ 800  |
| `GET /matches/[id]` (страница) | 200 |    78.4 |   113.0 |   118.3 | —          |
| `GET /api/v1/leaderboard`      | 200 |    23.1 |    28.1 |    35.1 | —          |
| `GET /leaderboard` (страница)  | 200 |    74.8 |    97.1 |   116.3 | —          |

Все ответы — 200. Приватная история и прием прогноза через HTTP не мерились (нужна сессия GitHub); на уровне
БД это `list_my_bets` (p95 16 мс) и `place_bet` (p95 18 мс) — цели 1000 и 1500 мс.

## Мобильный LCP

Chromium, Pixel 5 (360 × 740), CPU замедлен ×4, сеть: задержка 150 мс, 1.6 Мбит/с вниз. Три прогона, медиана.
Сервер локальный, поэтому реальная задержка до Vercel не учтена.

| Страница       | Медиана LCP, мс | Прогоны, мс   | JS, КБ (передано) |
| -------------- | --------------: | ------------- | ----------------: |
| `/`            |             748 | 776, 748, 632 |               136 |
| `/matches`     |             628 | 588, 628, 696 |               137 |
| `/leaderboard` |             728 | 728, 936, 684 |           131–136 |

Цель §14.2 — LCP ≤ 2.5 с — выполнена с запасом на этом профиле.

## Не измерено

- Реакция UI на действие (≤ 100 мс): в demo нет интерактивного купона, а сценарий с входом требует GitHub-сессии.
  Будет измерено вручную (DevTools → Performance, INP) на этапе 11.
- Облачные p95 и холодный старт Vercel, работа под реальной сетью — этап 11.
- Нагрузка выше 10 одновременных запросов — квоты бесплатных тарифов (§14.1) не стоит расходовать на стресс-тест.
